## Weak Area Retested

Pipeline State and Result-Set Reasoning

The retest focused on understanding how the current result set changes after `where` and how subsequent `stats` commands operate on the remaining rows or existing field values.

Key distinctions reinforced:

- `where` filters the current result rows.
- `stats count` counts the current result rows.
- `stats sum(count)` sums existing values in the `count` field.
- `stats avg(count)` averages existing values in the `count` field.
- Filtering happens before the next command in the pipeline.
- A later transforming command operates on the result set produced by the preceding commands.
